# Tailored faculty applications

Create one subdirectory per real institution and position, named in lowercase
hyphenated form, e.g. `university-name-assistant-professor-ece/`. Add
`variant.json` with a `baseVariant` of `faculty`, `faculty_comprehensive`,
or `academic_cv`. All other fields override the selected base configuration.

Do not add a dummy application: create one only when a job posting is available.
Faculty applications may later include research and teaching statements in their
institution-specific folder. Preserve the generic CV and resume as shared masters.

See `../README.md` for the builder and output locations.
