# Resume Profiles

Reusable configurations for the resume families. These are not job applications and do not contain generated PDFs.

- [Industry profiles](industry/README.md): reusable generic, comprehensive, AI/ML, GenAI, wireless, healthcare, and finance variants.
- [Faculty profiles](faculty/README.md): generic faculty resume, comprehensive faculty resume, and full academic CV.

Create or modify a profile here when the change should be reusable across multiple applications. Keep institution- or employer-specific adjustments under `job-applications/`.
