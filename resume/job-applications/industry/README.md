# Industry Job Applications

Each employer-specific folder contains one tailored LaTeX resume source, `metadata.json`, a positioning/quality-control README, and the generated PDF. The builder uses a temporary directory for LaTeX intermediates so the application folder stays uncluttered.

Build all standalone LaTeX job applications (industry and legacy faculty):

```bash
python resume/build_tailored.py --all
```

Build one application:

```bash
python resume/build_tailored.py --job cybercoders-senior-ml-engineer
```

The resulting PDF and concise `build-report.json` are written directly into the matching application folder. The Ohio State faculty application is also a standalone LaTeX source and is compiled by this builder; profile-based faculty applications are generated by `build.py`. Reusable base profiles remain under `resume/resume-profiles/industry/`; generic profile PDFs are under `resume/generic-resume/industry/`.
