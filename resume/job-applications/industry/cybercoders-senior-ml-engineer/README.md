# CyberCoders — Senior Machine Learning Engineer

Job-specific resume tailored from the reusable AI/ML resume.

## Positioning
This version emphasizes:
- Python and deep-learning engineering
- GANs and autoencoder-based generative/representation learning
- end-to-end training, validation and production-oriented ML
- scalable data pipelines with Databricks/Spark
- Docker, Kubernetes, CI/CD and reproducible repositories
- cross-functional work with engineers/scientists/domain experts
- mentoring, documentation and research-to-production translation

It intentionally does not claim unsupported hands-on experience with JAX, diffusion models, VAEs, Airflow, biomolecular simulation, mixed-precision training or deployment-side model compression.

## Build

Windows:
```powershell
.\resume\.venv\Scripts\python.exe resume\build_tailored.py --job cybercoders-senior-ml-engineer
```

Linux / Codespaces:
```bash
python resume/build_tailored.py --job cybercoders-senior-ml-engineer
```
